# ProsMem

**Remembering the Future: Interrupt-Driven Prospective Memory for LLM Agents.**

ProsMem is the first agent memory architecture that endows large language
model (LLM) agents with *prospective memory* (PM): the ability to remember
and execute a planned action at the right future moment. Existing agent
memories are retrospective by construction — they store past content and
surface it on explicit query, with no mechanism for a stored trigger
condition to fire on its own. ProsMem closes this gap with an
interrupt-driven design: an intention registry (interrupt-vector-table
analogue), a dual-pathway retrieval engine that operationalizes McDaniel &
Einstein's multiprocess theory (a fast associative path for focal cues and a
gated strategic LLM monitor for non-focal and activity cues), priority
arbitration, an eight-state intention lifecycle with commission-proof
deactivation, and isolated interrupt execution that leaves the foreground
task untouched.

This repository contains the framework, **ProsMem-Bench** (the first agent
PM benchmark: 185 multi-turn samples across 12 categories), and the runners
that reproduce every experiment in the paper.

## Layout

```
prosmem/
  core/        Intention / TriggerCondition / Registry (SQLite persistence)
  retrieval/   Associative path, TimeChecker, Strategic monitor, engine
  agent/       ProsMem agent loop, runtime intention encoder, LLM client,
               baseline agents (Vanilla, NaiveReminder, Mem0, A-MEM,
               GenAgents, MemoryBank, LightMem, Zep/Graphiti, EverMemOS),
               A-MEM+PM composability agent
  bench/       ProsMem-Bench (golden_samples.json, 185 samples),
               evaluator (4-tier metrics), LoCoMo loader, e2e probe
run_*.py       One runner per paper experiment (see below)
scripts/       Bench generator, significance statistics, dormancy check
```

## Install and configure

```bash
pip install -e .           # python >= 3.10
cp .env.example .env       # set OPENAI_BASE_URL + OPENAI_API_KEY
```

ProsMem talks to any OpenAI-compatible chat-completions endpoint; point
`OPENAI_BASE_URL` at your serving provider and set `OPENAI_API_KEY`
accordingly. Model identifiers in `prosmem/core/config.py` follow the
vendor/model convention; adjust them to your endpoint's catalog if it names
models differently. The embedding model (`BAAI/bge-small-en-v1.5`) runs
locally via sentence-transformers and needs no key.

Baselines with third-party backends need their own packages, installed only
if you run them: `mem0ai`, `chromadb` (A-MEM/GenAgents/MemoryBank stores),
`lightmem`, `graphiti-core` + a Neo4j instance (Zep), and `everos`. The
ProsMem agent itself needs none of these.

## Reproducing the paper

Every result in the paper is regenerated by these runners; each writes
per-sample row-level records from which all aggregate numbers derive.
Outputs land under `results/` (gitignored); `scripts/stats.py` consumes
the main-table and ablation outputs — its docstring lists the expected
filenames to pass as `--out`.

| Experiment | Runner |
|---|---|
| Main results (10 agents, 4 backbones) | `run_main_table.py` |
| Ablations (Assoc-Only / Monitor-Only / No-II / Static) | `run_ablation.py` |
| End-to-end natural-language delegation | `run_e2e_probe.py`, `run_e2e_baselines.py` |
| Composability (A-MEM+PM) | `run_composability.py` |
| Dormancy check (PM layer is a zero-token no-op on QA turns) | `scripts/verify_dormancy.py` |
| LoCoMo harness (dormancy verification setting) | `run_locomo.py` |
| Significance battery (McNemar / Cohen's h / bootstrap) | `scripts/stats.py` |
| Bench construction pipeline | `scripts/generate_bench.py` |

## ProsMem-Bench

The 185 samples live in `prosmem/bench/golden_samples.json` (12 categories:
event-based A1–A3, time-based B1–B3, activity-based C1–C3, composite D1–D3
with commission/omission/content failure-mode probes). Each sample is an
evaluation-only multi-turn trajectory with ground-truth trigger turns. The
end-to-end probe (`prosmem/bench/probes/`) supplies the natural-language
delegation utterances used by the e2e experiment.
